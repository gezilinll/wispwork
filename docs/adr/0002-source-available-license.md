# License Wisp as noncommercial source-available software

Code and repository material default to PolyForm Noncommercial 1.0.0 so people
may study, modify, and share Wisp for permitted noncommercial purposes while
commercial use requires a separate written license. Explicitly marked original
non-code content may use CC BY-NC-SA 4.0, and project marks remain outside both
grants. This prevents Wisp from being described as Open Source under the OSI
definition. The standard license preserves notices but does not force changes
back to the original GitHub repository; upstream return remains contribution
policy unless a lawyer-reviewed custom reciprocal license replaces this ADR.

Consequences: substantial external contributions require an appropriate CLA
before merge if the project is to retain dual-licensing ability, and every
distribution must preserve the official license terms and `Required Notice:`
lines.
